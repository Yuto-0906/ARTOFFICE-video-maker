macOS 15以降のApple Silicon・Intel向け試験版を追加しました。Windows版と同じ画面で，動画の読み込み，トリミング，結合，日本語のバンド名表示，チャプターとサムネイルの作成を行えます。

- MシリーズのMac：macos-arm64.dmgを選んでください。
- IntelのMac：macos-x64.dmgを選んでください。
- Windows：windows-x64.zipを展開してください。

Mac版のDMGを開き，アプリをApplicationsへドラッグしてから起動します。動画処理ツールと日本語フォントは同梱されているため，Homebrewなどの導入は不要です。配布用のMac版はDeveloper ID署名・公証を行っています。

Mac版は試験版です。自動検証では両CPUのビルド，1080p・1440pの書き出し，結合，日本語タイトル，サムネイル，キャンセルと移動後の同梱物を確認します。画面操作・動画プレビュー・実機でのハードウェア高速化は未確認です。実機で確認する項目はアプリ同梱のMAC_TEST_CHECKLIST.mdを参照してください。

既存の0.1.0～0.3.0のプロジェクトを読み込めます。プロジェクトに記録した元動画・写真のパスは，使用するパソコン上に存在する必要があります。
