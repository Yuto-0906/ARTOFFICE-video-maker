# ARTOFFICE広報動画作成ソフト 使い方

Windows 10・11の64bit版と，macOS 15以降のApple Silicon・Intelに対応します。Mac版は試験版です。署名・公証済みDMGからアプリをApplicationsへコピーしてください。追加ツールのインストールは不要です。画面操作や動画プレビューの実機確認状況はMAC_TEST_CHECKLIST.mdを参照してください。

## 1．動画

1. 動画のフォルダーを画面にドロップするか，「フォルダーから追加」「ファイルを追加」で読み込みます。対応形式はMP4，MKV，MOV，WebM，MTS，M2TS，AVI，WMVです。
2. ファイル名の先頭の番号（`01_MOSHIMO.mp4`，`2 軽音バンド.mkv`など）が出演順になります。番号が無いファイルは最後に並び，ファイル名がバンド名になります。
3. イベント名は完成ファイル名になります。最初はフォルダー名が入ります。
4. バンド名は名前をクリックして直せます。順番は行の左端のドラッグか，上下の矢印で変えます。元のファイル名は変わりません。
5. 赤い線が付いた行は書き出せません。行に理由が表示されます。番号が黄色の行は，同じ番号の動画が他にもあります。

1バンドの演奏が複数のファイルに分かれている場合は，2本目以降を1本目のすぐ下に並べて「前の動画の続き」にチェックを入れます。続きの間はクロスフェードなしでつながり，バンド名とチャプターは1本目にだけ入ります。

## 2．カット

1. 左の一覧からバンドを選びます。
2. 再生して，残したい始まりで「ここから開始」（I），終わりで「ここで終了」（O）を押します。
3. 時間軸の両端のつまみをドラッグしても調整できます。時刻を入力した場合はEnterで確定します。
4. Space：再生・停止，←→：1フレーム，Shift＋←→：1秒，Home／End：開始位置／終了の3秒前，↑↓：前後の動画，F：全画面。

位置はフレーム単位で保存します。開始位置のフレームは含み，終了位置のフレームは含みません。

## 3．サムネイル

集合写真をドロップするか「写真を選ぶ」で選び，16:9の枠の中で移動・拡大します。JPEG，PNG，HEIC，HEIF，WebP，TIFF，BMP，AVIF，GIF（先頭のコマ）に対応します。保存形式はJPEGかPNGです。写真を選ばなければサムネイルは作りません。

## 4．書き出し

1. ファイル名と保存先を確認します。保存先は最初，一覧の1本目の動画と同じフォルダーです。「変更…」で選んだ保存先はプロジェクトに記憶されます。
2. 画質とフレームレートを選びます。通常は「元の動画と同じ」で構いません。
3. 「書き出す」を押します。直す必要があることはボタンの上に表示されます。
4. 終わったら「フォルダーで表示」で完成ファイルの場所を確認できます。チャプターは右側の「コピー」でYouTubeの概要欄に貼り付けられます。

WindowsではNVENC，Quick Sync，AMF，Media Foundation，libx264の順に使える方式を選びます。MacではVideoToolboxを優先し，使えなければlibx264で書き出します。同じ名前のファイルがある場合は上書きを確認します。中止・失敗したときは途中のファイルを消し，上書き前のファイルを元に戻します。

次のファイルが保存先に作られます。

- `イベント名.mp4`
- `イベント名_チャプター.txt`
- `イベント名_サムネイル.jpg`または`イベント名_サムネイル.png`（サムネイルを設定したときだけ）

YouTubeでは，チャプターが3つ未満のときや10秒未満のチャプターがあるときは表示されません。

## 保存と再開

- 「保存」（Ctrl＋S／⌘S）で`.aovproj`ファイルに保存します。一度保存した後の変更は自動で上書き保存します。
- 「開く」（Ctrl＋O／⌘O）で続きから編集できます。「元に戻す」（Ctrl＋Z／⌘Z）で直前の操作を取り消せます。
- 「やり直す」（WindowsはCtrl＋YまたはCtrl＋Shift＋Z，Macは⌘＋Shift＋Z）で取り消した操作を戻せます。
- 一度も保存していないプロジェクトを閉じるときは，保存するか確認します。

プロジェクトファイルに動画は含まれません。動画を移動した場合は，動画の画面の「見つからない動画を探す」で新しいフォルダーを選びます。

## 完成動画の固定仕様

- MP4，H.264 High Profile，プログレッシブ，YUV 4:2:0，BT.709。フレームレートは先頭動画に合わせるか，23.976・24・25・29.97・30・50・59.94・60fpsを指定
- 解像度の自動設定は先頭動画の幅・高さを使用し，ビットレートは画素数に応じて設定
- 1080pは1920×1080・平均15Mbps
- 1440pは2560×1440・平均30Mbps
- AAC-LC，48kHz，ステレオ，384kbps，Fast Start

書き出し中はWindows・Macともに通常の自動スリープを抑止し，完了・キャンセル・失敗時に解除します。ノートPCではAC電源への接続を推奨します。
