# ARTOFFICE広報動画作成ソフト 使い方

## 1．動画読込

1. イベント名を入力します。この名前が完成ファイル名になります。
2. 「フォルダーを選択」または「MP4を選択」で動画を読み込みます。
3. ファイル名は`出演順_バンド名.MP4`にします。例は`1_MOSHIMO.MP4`です。
4. 重複番号や不正な名前が表示された場合は元ファイルを確認します。バンド名はアプリ内で修正でき，左端の「⠿」をドラッグするか「↑」「↓」を押して順番も変更できます。元ファイル名は変わりません。
5. 「書き出し時に変換します」はエラーではありません。解像度，フレームレート，形式が完成動画の仕様へ自動変換されることを示します。

### 分割された動画を連結する

1. パート2をパート1のすぐ下へ移動します。
2. パート2の行にある「前と連結」を押します。
3. 3本以上に分かれている場合は，パート3以降にも同じ操作を行います。

連結したパート間はクロスフェードなしで直結します。バンド名表示とチャプターは最初のパートにだけ入り，並べ替え時は連結した動画が一緒に移動します。

## 2．トリミング

1. 左の一覧からバンドを選び，動画を再生して開始・終了位置を探します。
2. 開始点側と終了点側の「現在位置を設定」，範囲ハンドル，時刻入力，前後1フレーム移動を使って調整します。
3. 位置はフレーム番号で保存されます。開始位置は含み，終了位置は含まない仕様です。
4. 別バンドとの境目は「0.5秒クロスフェードを確認」，分割動画の境目は「連結部分を確認」で確認できます。

## 3．サムネイル

集合写真を選択し，16:9枠の中で移動・拡大します。JPG，PNG，HEIC，HEIFに対応します。設定しなければサムネイルJPEGは作りません。画像へ文字は追加しません。

## 4．書き出し

1. 1080pまたは1440pを選び，保存先フォルダーを指定します。
2. チャプターの警告を確認します。3章未満，または10秒未満の章があってもテキストは作成されますが，YouTube側で自動認識されない場合があります。
3. 「書き出し開始」を押します。利用可能ならNVENC，Quick Sync，AMFの順にGPUを試し，Media Foundation，libx264へ自動で切り替えます。
4. 同名ファイルがある場合だけ上書き確認が表示されます。キャンセルや失敗時には一時成果物を削除し，上書き前の完成ファイルがある場合は元へ戻します。

次のファイルが同じ保存先へ作られます。

- `イベント名.mp4`
- `イベント名_チャプター.txt`
- `イベント名_サムネイル.jpg`（サムネイル設定時のみ）

## プロジェクト保存と再リンク

「保存」「名前を付けて保存」で`.aovproj`を保存します。自動保存はありません。未保存のまま閉じると，保存・破棄・キャンセルを選べます。

元動画はコピーされません。動画を移動・削除した場合は，対象項目の再リンク操作で，新しい保存場所のファイルを指定してください。元動画のサイズや更新日時が異なる場合は確認してから編集位置を見直してください。

## 完成動画の固定仕様

- MP4，H.264 High Profile，プログレッシブ，YUV 4:2:0，BT.709，59.94fps
- 1080pは1920×1080・平均15Mbps
- 1440pは2560×1440・平均30Mbps
- AAC-LC，48kHz，ステレオ，384kbps，Fast Start

長時間の書き出し中はWindowsのスリープを抑止し，終了後に解除します。ノートPCではAC電源への接続を推奨します。
